# 认识系统

IBL Rig 用一台 Raspberry Pi 5 管理整套训练装置。操作者通过浏览器完成训练，硬件控制器执行毫秒级动作，相机和数据系统同步记录整个过程。

## 系统组成

```text
浏览器 / 飞书
      │
      ▼
网页控制台
      │
      ▼
Raspberry Pi 5
ROS 2 实验服务
      │
      ├── 刺激显示器
      ├── OAK 四路相机
      ├── 数据记录
      ├── 行为声音
      └── RoboMaster C Board
                 │
                 ├── 转轮
                 ├── M2006 + C610
                 ├── 蠕动泵
                 └── 同步输入输出
```

## 网页控制台

网页控制台是日常使用入口。

主界面包含：

- 实验控制
- 实验设置
- 配置库
- 小鼠编号
- 预检
- 视频预览
- 表现统计
- 控制权
- 实验结果

一场训练通常从“实验设置”开始，在“表现统计”和“视频预览”中监看，最后进入数据处理和归档。

## 实验主机

主机使用 Raspberry Pi 5，运行 Ubuntu 24.04 和 ROS 2 Jazzy。

它负责：

- 读取训练配置
- 准备实验所需设备
- 将每个 Trial 发给硬件控制器
- 在 HDMI 屏幕上显示视觉刺激
- 播放行为声音
- 控制四路 OAK 相机
- 记录行为事件和录像
- 生成实验质量报告
- 上传 NAS
- 汇总到 W&B
- 写入飞书实验索引

主机使用 NVMe 保存实验数据，录像和行为日志直接写入本地高速存储。

## 硬件控制器

RoboMaster C Board 使用 STM32F407。

每个 Trial 的实时部分在控制器上运行，包括：

- 读取转轮位置
- 判断响应方向和阈值
- 控制 M2006 电机
- 控制奖励泵
- 产生同步信号
- 记录硬件事件
- 执行安全停止

控制器与 Raspberry Pi 通过 ST-Link/SWD 保持运行时通信。

## 转轮与力反馈

转轮连接 M2006 减速电机和 C610 电调。

控制器以 500 Hz 运行电机控制环。训练配置可以选择不同的力反馈模式，例如透明、阻尼、弹簧、棘轮和自适应透明模式。

正式训练配置使用 force profile 27。

## 视觉刺激

刺激显示器连接 Raspberry Pi 的 HDMI。

当前显示参数：

- 1920 × 1080
- 60 Hz
- 20 px/视觉°
- 转轮-屏幕增益 85.172 px/轮角°
- 中性灰背景亮度 0.5
- 80 px 光电二极管标记区

训练过程中，Gabor 刺激的位置直接跟随转轮角度。当前 ±35° 刺激距离屏幕中心 700 px，对应约 8.22° 的转轮行程。训练增益调整时，屏幕移动比例和响应行程同步变化。

## 行为声音

行为声音由 C Board 蜂鸣器产生：

- Go tone：4 kHz，100 ms
- Error sound：2 kHz 与 4 kHz 每 50 ms 交替一次，总时长 500 ms

声音和 Trial 使用同一块 STM32 控制器计时。

## 四路相机

相机系统使用 Luxonis OAK-FFC-4P。

四路传感器：

- CAM_A：OV9782 彩色全局快门
- CAM_B：OV9282 黑白全局快门
- CAM_C：OV9282 黑白全局快门
- CAM_D：OV9282 黑白全局快门

当前录像规格：

- 1280 × 800
- 30 fps
- H.265
- 12 Mbps / 路
- USB 3
- 四路同时录制

浏览器同时显示主画面和三路缩略图。

## 一场训练怎样运行

```text
选择训练配置
      ↓
输入小鼠编号
      ↓
锁定配置
      ↓
预检
      ↓
开始实验
      ↓
视觉刺激 + 转轮 + 声音 + 奖励
      ↓
四路录像 + 行为记录
      ↓
结束实验
      ↓
行为分析
      ↓
NAS + W&B + 飞书
```

## 实验结束后

系统会整理：

- Trial 结果
- 正确率
- 奖励统计
- 四路视频
- 每帧时间信息
- 实验质量报告
- NAS 路径
- W&B 链接
- 飞书实验记录
