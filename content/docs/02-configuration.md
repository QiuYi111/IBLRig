# 配置文件

每次实验都从一份训练配置开始。

配置文件使用 YAML 格式，网页控制台把常用参数直接显示为可编辑项。操作者可以选择已有配置、为本次实验做临时修改，也可以在配置库中保存新版本。

## 配置库

当前配置库包含：

- 正式预训练
- 正式训练
- 自动奖励预训练
- 在线训练
- 训练验证配置
- 静音验证配置

系统内置配置直接出现在“训练配置”下拉框中。

个人配置可以保存多个版本，并支持归档和恢复。

## 配置版本

每个配置都有：

- 配置 ID
- 显示名称
- 版本号
- 训练类型
- 参数
- 备注

编辑配置后保存，会形成新的版本。

“查看修改差异”会显示本次修改前后的 YAML 内容。

## 临时修改

“临时修改”适合只影响本次实验的调整。

例如：

- 奖励时长从 2 s 调到 1 s
- Trial 上限从 2000 调到 500
- 响应窗口从 60 s 调到 30 s
- 调整刺激对比度
- 调整力反馈 profile

点击“清除临时修改”即可恢复当前模板值。

## 锁定配置

点击“锁定配置”后，页面生成本次实验的最终配置。

锁定页显示：

- 小鼠编号
- 模板
- 会话编号
- 校验值
- 临时修改差异
- 最终配置

预检和实验都使用这份最终配置。

## 正式预训练

正式预训练用于小鼠熟悉装置、视觉刺激和奖励位置。

当前参数：

| 项目 | 当前值 |
|---|---:|
| 刺激位置 | ±35° |
| 对比度 | 100% |
| Gabor 方向 | 0° |
| 空间频率 | 0.1 cycles/° |
| Gabor 尺寸 σ | 7° |
| 侧边停留时间 | 10 ± 2 s |
| 到中心后的奖励等待 | 0.5 s |
| 奖励泵动作 | 反转 2 s |
| 奖励后的显示时间 | 0.5 s |
| Trial 上限 | 400 |

每次实验使用独立的随机序列。

## 正式训练

正式训练使用 ChoiceWorld 六阶段训练流程。

当前基础参数：

| 项目 | 当前值 |
|---|---:|
| 刺激位置 | ±35° |
| Gabor 方向 | 0° |
| 空间频率 | 0.1 cycles/° |
| Gabor 尺寸 σ | 7° |
| 转轮-屏幕增益 | 85.172 px/轮角° |
| 静止阈值 | 2° |
| 基础静止时间 | 200 ms |
| 响应窗口 | 60 s |
| 正确反馈 | 2.2 s |
| 错误反馈 | 2.0 s |
| 无响应反馈 | 2.0 s |
| Trial 间隔 | 0.5 s |
| Go cue | 开启 |
| 力反馈 | profile 27 |
| Trial 上限 | 2000 |

奖励泵使用反转 2 s。

## 训练阶段

正式训练会根据同一只小鼠的连续训练记录延续当前阶段。

系统会保留：

- 当前训练阶段
- 已完成 Trial 数
- 各刺激条件表现
- 最近表现窗口
- 当前奖励设置
- 当前转轮增益

下一次选择同一小鼠时，训练从保存状态继续。

## 小鼠编号

小鼠编号用于关联连续训练记录。

同一只小鼠持续使用同一个编号，可以在“表现统计”中查看连续训练结果。

## 配置中的物理量

最常接触的几类参数：

### 视觉

- 刺激位置：视觉刺激起始角度
- 对比度：Gabor 明暗对比
- 方向：Gabor 条纹方向
- 空间频率：每视觉角度内的明暗周期
- σ：Gabor 包络大小

### 转轮

- 转轮-屏幕增益：每转动 1° 转轮，视觉刺激在屏幕上移动的像素数
- 静止阈值：Trial 开始前允许的转轮运动范围
- 力反馈 profile：转轮阻尼、惯性和拟物反馈设置

当前正式训练使用 **85.172 px/轮角°**。±35° 刺激的起始位置距离中心 700 px，因此标准增益下约转动 **8.22°** 到达中心。训练中的自适应增益减半时，映射变为 **42.586 px/轮角°**，到中心的转轮行程约为 **16.44°**。

### 时间

- 静止时间
- 响应窗口
- 正确反馈
- 错误反馈
- Trial 间隔

### 奖励

- 奖励方向
- 奖励时长
- 排气方向

### 声音

- Go cue
- Error noise

完整字段、单位和默认值见 [实验与设备参数 Reference](/IBLRig/reference/configuration/)。
