# IBL Rig

从一次实验的完整链路开始阅读：

1. **认识系统**：系统组成、数据流和控制流。
2. **Quick Start**：从登录到完成一次 Session。
3. **配置文件**：模板、参数、编译、版本和训练状态。
4. **身份与权限**：飞书认证、控制权、接管和审计。
5. **实验数据**：事件、视频、分析、NAS、W&B 和飞书索引。
6. **硬件介绍**：主机、MCU、电机、泵、相机、显示、同步和机械结构。
7. **ROS 2**：Supervisor、Runtime Graph、Gateway、Recorder、Camera、Stimulus。

详细接口表集中在 [Reference](/IBLRig/reference/)。
