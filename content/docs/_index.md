# IBL Rig

建议按下面的顺序阅读：

1. **认识系统**：了解一场训练怎样从网页控制台运行到硬件。
2. **Quick Start**：完成第一次实验。
3. **配置文件**：理解训练模板和每个参数的物理意义。
4. **身份与权限**：理解登录、控制权和接管。
5. **实验数据**：找到录像、行为结果、NAS、W&B 和飞书记录。
6. **硬件介绍**：了解每个硬件的规格、连接方式和用途。
7. **ROS 2**：了解主机上的实验服务以及常用检查方法。
8. **Daemon 与自恢复**：了解后台服务、按需设备启动和故障恢复。
9. **Chaos / HIL**：了解随机 HIL、竞态测试、规则和失败证据包。
10. **与 IBL 原版对比**：理解平台与 IBL 原版在架构、硬件、时序、数据和验证上的关系。

需要查数值、节点名和话题名时，直接进入 [Reference](/IBLRig/reference/)。
