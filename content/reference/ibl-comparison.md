# IBL 对比

本页逐项列出 IBL Rig 与 IBL 原版装置的参数和实现差异。概述见 [09 · 与 IBL 原版对比](../../docs/09-ibl-comparison/)。

## 数据来源

| 系统 | 来源 |
|---|---|
| IBL 原版 | [int-brain-lab/iblrig](https://github.com/int-brain-lab/iblrig) 主分支，2026-06 |
| IBL Rig | 本文档站 Reference 各页当前值 |

IBL 原版参数主要取自：

| 文件 | 内容 |
|---|---|
| `iblrig/base_choice_world_params.yaml` | ChoiceWorld 公共参数 |
| `iblrig_tasks/_iblrig_tasks_habituationChoiceWorld/task_parameters.yaml` | 适应期任务 |
| `iblrig_tasks/_iblrig_tasks_trainingChoiceWorld/task_parameters.yaml` | 训练任务 |
| `iblrig/base_biased_choice_world_params.yaml` | 偏置 block 任务 |
| `iblrig/choiceworld.py` | 训练阶段、对比度集合、自适应奖励 |
| `iblrig/base_choice_world.py` | 状态机、静止期、debias、block |
| `iblrig/pydantic_definitions.py` | 转轮直径 |
| `settings/hardware_settings_template.yaml` | 屏幕、Frame2TTL、阀门、声音 |
| `devices/camera_recordings/*.bonsai` | 相机帧率 |

## 状态说明

| 标记 | 含义 |
|---|---|
| 一致 | 数值与语义相同 |
| 等效 | 实现不同，行为学效果应相同 |
| 不同 | 数值或语义存在差异 |
| 未实现 | IBL 原版具备，IBL Rig 当前没有 |
| 平台扩展 | IBL Rig 具备，IBL 原版没有 |
| 待核对 | 文档中尚无足够信息判断 |

| 等待静止上限 | — | 600 s | 平台扩展 |

## 4. 训练阶段与对比度

### 4.1 IBL 原版训练阶段

对比度集合由 `choiceworld.training_contrasts_probabilities` 定义。

| 阶段 | 对比度集合 | 升级条件 |
|---|---|---|
| 0 | 1.0, 0.5 | 四个有符号对比度（±1、±0.5）最近 50 次正确率均 > 80% |
| 1 | + 0.25 | ±0.25 最近 50 次正确率均 > 80% |
| 2 | + 0.125 | 本阶段 200 Trial |
| 3 | + 0.0625 | 本阶段 200 Trial |
| 4 | + 0 | 本阶段 200 Trial |
| 5 | 移除 0.5 | 最终阶段 |

- 阶段按小鼠跨会话延续。
- Debias 只在阶段 0–4 启用。

## 5. 转轮与刺激几何

### 5.1 增益定义

| 项目 | IBL 原版 | IBL Rig |
|---|---|---|
| 增益单位 | 视角° / mm 转轮表面位移 | px / 转轮角° |
| 初始增益 | 8 °/mm | 85.172 px/° |
| 最终增益 | 4 °/mm | 42.586 px/° |
| 切换条件 | 单场完成 200 个有响应 Trial 后恢复 4 °/mm | 训练自适应，从 8 调整为 4 |
| 转轮直径 | 62 mm | — |
| 视觉几何 | 由屏幕距离与分辨率决定 | 20 px/视角° |

### 5.2 换算

IBL 原版转轮每转 1° 对应的表面位移：

```text
62 mm × π / 360 = 0.5411 mm/°
```

初始增益 8 °/mm 时：

```text
8 × 0.5411 = 4.328 视角° / 转轮°
35 / 4.328 = 8.09 转轮°
```

IBL Rig 初始增益：

```text
85.172 / 20 = 4.259 视角° / 转轮°
35 / 4.259 = 8.22 转轮°
```

| 项目 | IBL 原版 | IBL Rig | 差异 |
|---|---|---|---|
| 初始增益 | 4.328 视角°/转轮° | 4.259 视角°/转轮° | −1.6% |
| 到达中心所需转轮行程 | 8.09° | 8.22° | +1.6% |
| 最终增益下的行程 | 16.17° | 16.44° | +1.6% |

IBL Rig 的增益相当于 IBL 公式配合约 61.0 mm 的转轮直径。若 IBL Rig 转轮实际直径为 62 mm，增益应为 86.57 px/°。**待核对**：IBL Rig 转轮直径与增益推导依据。

### 5.3 转轮硬件

| 项目 | IBL 原版 | IBL Rig | 状态 |
|---|---|---|---|
| 驱动 | 无源 | M2006 P36 减速电机 + C610 电调 | 平台扩展 |
| 位置测量 | 旋转编码器 + Bpod 编码器模块 | 电机编码器，经 36:1 减速 | 不同 |
| 阈值判定 | 编码器模块硬件阈值事件 | STM32 判定 | 等效 |
| 力反馈 | 无 | 阻尼、弹簧、惯性、棘轮、透明、自适应透明等 | 平台扩展 |
| 控制频率 | — | 500 Hz | 平台扩展 |
| 正式训练手感 | 无源转轮 | force profile 27 | 待核对：与无源转轮的机械等效性 |
| 最大持续力矩 | — | 1 N·m（电机额定） | 需软件与固件限幅 |

透明模式与无源转轮的等效性需通过台架测试确认：

| 测量项 | 方法 |
|---|---|
| 起动力矩 | 静止到开始转动所需力矩 |
| 等效惯量 | 自由滑行衰减 |

## 6. 奖励

| 项目 | IBL 原版 | IBL Rig | 状态 |
|---|---|---|---|
| 执行器 | 电磁阀（Valve1） | 四线步进蠕动泵 + DRV8834 | 不同 |
| 科学变量 | 体积（µL） | 当前为泵动作时长（ms） | 不同 |
| 校准方式 | 称重，开阀时间 → 体积曲线 | 脉冲数 → 体积 | 等效 |
| 校准范围 | 开阀 40–140 ms，每滴 1.25–2.75 mg | 14,399,993 pulse / 5.5 mL | — |
| 分辨率 | 由开阀时间决定 | 0.382 nL / pulse | 平台扩展 |
| 出水速度 | 数十毫秒内完成 | 约 4.58 µL/s | 不同 |
| 适应期单次奖励 | 3 µL | 2000 ms | 不同 |
| 训练单次奖励 | 3 µL 起，1.5–3 µL 自适应 | 2000 ms | 不同 |
| 自适应规则 | 上一场摄水不足体重 × 40 µL/g 时 +0.1 µL；否则上一场 > 200 Trial 时 −0.1 µL；限制在 1.5–3 µL | — | 未实现 |
| 奖励液 | 10% 蔗糖水 | — | 待核对 |
| 双向与排气 | 否 | 是 | 平台扩展 |

按当前泵校准推算，2000 ms 泵动作对应约：

```text
4.58 µL/s × 2 s ≈ 9.2 µL
```

约为 IBL 初始奖励的 3 倍。平台将统一为体积语义：

```text
目标体积 (µL) → 泵校准 → 脉冲数
```

以 3 µL 为例，需 7,855 个脉冲；在 12 kHz STEP 频率下耗时约 0.65 s。

## 13. 软件与通信

| 项目 | IBL 原版 | IBL Rig |
|---|---|---|
| 主机系统 | Windows | Ubuntu 24.04 |
| 主机硬件 | PC | Raspberry Pi 5，8 GB |
| 任务框架 | Python，mixin 组合任务类 | ROS 2 Jazzy 节点 |
| 刺激参数下发 | OSC / UDP，本机端口 7110 | ROS 2 |
| 刺激状态指令 | Bpod → 编码器模块串口 → Bonsai | STM32 → 主机 → 渲染器 |
| 相机控制 | Python 启动 Bonsai 子进程，OSC 端口 7111 | ROS 2 设备能力 |
| 麦克风控制 | Bonsai 子进程，OSC 端口 7112 | — |
| 多机协调 | asyncio TCP / UDP 自定义消息 | ROS 2 / DDS |
| 进程管理 | 按会话启动与清理 | systemd + Supervisor 按需启动 |
| 故障恢复 | 人工 | 分级自动恢复：重启能力、SWD 复位、USB 复位、重连、健康验证 |
| 运行时数量 | 3（Python、Bpod 固件、Bonsai/.NET） | 2（主机 Linux、STM32 FreeRTOS） |
| 界面 | Qt 桌面程序 | 网页控制台 |
| 远程访问 | — | 支持 |
| 多人控制 | — | 控制权租约、接管、审计 |
| 配置 | YAML | 配置库：版本、差异、临时覆盖、锁定 |
| 会话配置 | 写入会话文件 | 不可变会话配置 |

IBL 原版 ChoiceWorld 单个 Trial 的数据流：

```text
Python
├── OSC/UDP → Bonsai            Trial 参数
├── 串口 → Bpod                 状态机
│    ├── 串口 → 编码器模块 → Bonsai   刺激显示/冻结/居中
│    ├── 串口 → Harp 声卡             声音
│    └── soft code → Python → 声卡    声音（非 Harp）
└── 子进程 → Bonsai             相机录制
```

IBL Rig：

```text
网页 → ROS 2 → Supervisor → SWD → STM32
                                   ├── CAN → 电机
                                   ├── STEP/DIR → 泵
                                   ├── 定时器 → 蜂鸣器
                                   └── GPIO → 同步
主机 → HDMI → 刺激显示
OAK → USB 3 → 主机 → NVMe
```

## 16. 差异汇总

### 16.1 影响行为学可比性，建议优先处理

| 项目 | 差异 | 建议 |
|---|---|---|
| 奖励体积 | 约 9.2 µL vs 3 µL，且无自适应 | 改为按体积给水，实现 1.5–3 µL 自适应 |
| 正确反馈时长 | 2.2 s vs 1 s | 奖励改为体积后恢复 1 s |
| 转轮机械特性 | 电机透明模式 vs 无源转轮 | 台架测试起动力矩、惯量、摩擦、齿隙 |
| 声音 | 4 kHz 蜂鸣 + 交替音 vs 5 kHz 纯音 + 白噪声 | 换用扬声器，校准声压 |
| 增益 | 相差 1.6% | 核对转轮直径 |
| 静止期 | 需确认是否含随机部分 | 对齐 IBL 截断指数分布 |
| 训练阶段 | 需公开阶段表 | 在参数页补充 |

### 16.2 影响时序精度

| 项目 | 建议 |
|---|---|
| 刺激出现时间 | 光电二极管接入 STM32 定时器捕获 |
| 相机同步 | 启用 OAK 外触发，或将帧 strobe 接入 STM32 |
| 延迟 | 实测第 10 节所列各链路 |

### 16.3 影响数据互通

| 项目 | 建议 |
|---|---|
| ALF 导出 | 实现 trials 表与转轮数据导出 |
| 任务覆盖 | 优先实现 `biasedChoiceWorld` |
